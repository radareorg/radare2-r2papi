# AGENTS.md

## Edit These Files

- Edit `async/*.ts`
- Treat `async/` as the source of truth

Main files:

- `async/r2papi.ts`: main public API
- `async/r2pipe.ts`: transport interfaces and wrappers
- `async/outputs.ts`: typed shapes for r2 `*j` command output — extend here, keep it in sync with real r2 output
- `async/shell.ts`: host shell + r2 virtual-filesystem helpers
- `async/esil.ts`: ESIL helpers
- `async/ai.ts`: AI helpers
- `async/index.ts`: public exports

`outputs.ts` is the contract between raw r2 JSON and the typed API. When you touch a
command invocation, update the matching interface in the same commit. Sample the real
output with `r2 -q -2 -c '<cmd>' /bin/ls` and trust that, not memory.

## Generated Files

- `sync/` is autogenerated from `async/` by a sed transform (`make sync`)
- `build/` is created by `make build`; `async/*.js|d.ts` by `npm run abuild`
- do not hand-edit any of the above

## How Build Works

- `make sync`
  - copies selected files from `async/` to `sync/` (list in `FILES` in the Makefile)
  - removes `async` and `await`
  - renames async types to sync types
  - rewrites `Promise<T>` to `T`
- `make build`
  - regenerates `sync/`, type-checks everything, emits `build/dist/` (declarations included)
  - also builds `build/*.r2.js` concatenation targets for the r2-internal bundle
- `npm run abuild`
  - compiles the async sources in place (artifacts are gitignored)

Because sync is produced by a simple text transform, write `async/` code so it still
makes sense after `async`/`await` are stripped: no multiline `Promise<...>` generic
arguments (the sed is line-based), no `async` used as an identifier, etc.

## Verification

Use these when relevant:

- `npm run lint` — eslint 9 flat config (`eslint.config.mjs`)
- `npm test` — lint + `abuild`
- `make build` — full clean build incl. sync flavor
- `npm run smoke` — drives the async API against a real r2 on /bin/ls
  (`tools/smoke.mjs`); skips cleanly when r2 is not installed

There is no automated test suite yet — don't overclaim verification. Typecheck + lint +
manual smoke is the current bar.

## API Rule

- Add or change public API in `async/`, regenerate derived outputs, and keep both flavors
  compiling. Prefer consistent, typed, high-level wrappers over raw command-string helpers.
- Any method that talks to r2 must be `async`. Never return `Promise<any>` from new public
  API — use `async/outputs.ts` types.
- Keep the r2 channel rules: prefer `call`/`callj` (literal) for interpolated strings,
  `cmd`/`cmdj` when r2 command syntax (`@`, `~`, `j`) is needed; quote user input.

## Layout gotchas

- `r2papi.r2.js` (repo root) is the r2-plugin bundle built by `make one`; it is gitignored.
- `R2_PAPI_SCRIPT=<path> r2 -j /bin/ls` loads that bundle inside r2's qjs shell.
  `r2 -i file.js` runs files through **node**, not r2 — don't confuse the two.
- `-c 'js ...'` is split on `;`, so multi-statement snippets break silently.
